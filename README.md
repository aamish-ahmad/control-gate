# Control Gate

**Control Gate** is an intent-native AI automation control platform that converts ambiguous business goals into validated executable specifications, governs AI execution through policy and human control, and records complete execution trajectories for optimization and accountability.

See [CONTROL_GATE_KNOWLEDGE_BASE.md](./CONTROL_GATE_KNOWLEDGE_BASE.md) for the canonical architectural specification and vision.

## Repository Structure

- `src/control_gate/`: Primary Python package.
- `tests/`: Automated tests suite.
- `evals/`: Evaluation benchmarks and test suits.
- `examples/`: Usage examples and reference configurations.
- `docs/`: Project documentation.
- `archive/`: Historical / legacy reference material.
